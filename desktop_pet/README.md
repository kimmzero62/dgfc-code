# 바탕화면 펫

움직이는 GIF 한 장으로 바탕화면(작업표시줄 위)을 돌아다니는 펫을 띄웁니다. Windows·Mac 모두 됩니다.

## 설치 (처음 한 번)

1. Python 3.10 이상 설치 (Windows는 설치할 때 **Add python.exe to PATH** 체크)
2. 이 폴더에서:
   ```
   pip install -r requirements.txt
   ```
3. 펫 그림(움직이는 GIF)을 `assets/pet.gif` 로 저장
   - 그림 파일은 저작권 때문에 저장소에 올리지 않습니다(`.gitignore` 처리).

## 실행

- Windows: `펫실행.bat` 더블클릭 (검은 창 없이 뜸)
- Mac/직접 실행: `python pet.py` (다른 그림: `python pet.py 경로/그림.gif`)
- PC 켤 때 자동 실행(Windows): `Win+R` → `shell:startup` → 열린 폴더에 `펫실행.bat` 바로가기 넣기

## 조작

| 동작 | 반응 |
|---|---|
| 클릭 | 하트·수줍음·손인사·점프 중 하나 + 소리(우나·뿌릣·이야) |
| 드래그 | "야다!!" 하며 들려 있다가, 놓으면 바닥으로 떨어짐 |
| 오른쪽 클릭 / 트레이 아이콘 | 크기(작게·보통·크게), 돌아다니기, 쉬는 시간 알림, 재우기·깨우기, 화면 가운데로, 종료 |
| 2분간 안 건드림 | 잠듦 (클릭하면 "하?") |
| 50분마다 | 손 흔들며 "뿌릣!" — 쉬는 시간 신호 |

설정(크기·돌아다니기·알림)은 다음 실행 때도 유지됩니다.

## 프레임 구성

9프레임 GIF는 프레임 순서대로 `기본, 손인사, 점프, 하트, 꼼지락, 놀람, 뒤돌기, 잠자기, 수줍음` 동작으로 씁니다
(`pet.py`의 `POSE`). 프레임 수가 다른 GIF는 그냥 반복 재생하면서 돌아다닙니다.
그림에 떠 있는 분홍 하트는 불러올 때 지웁니다(`REMOVE_HEARTS = False`로 되돌림).
말풍선 소리, 이동 속도, 잠드는 시간, 알림 간격은 `pet.py` 위쪽 설정에서 바꿀 수 있습니다.
